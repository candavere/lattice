Lattice

A deterministic, seedable 2D procedural strategy/tactical simulation environment. Same seed, same actions, same bytes — every time.

Demo trajectory

Seed 42, MCTS agent, 30 ticks. Recorded with lattice simulate and rendered as a single dependency-free CSS-animated SVG by lattice render --format svg.

Reproduce it yourself

  • dotnet run --project Cli -- simulate --seed 42 --agent mcts --steps 30
  • dotnet run --project Cli -- render --trajectory demo.jsonl --format svg --out demo.svg
Lattice — environment over agents. Compiled against the .NET base class library only; no external dependencies.
