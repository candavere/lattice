# ADR-001 — MapGraph is a graph over zones, not a grid

**Status:** accepted

## Context

The generator must produce a map of zones, resources, and choke points. The
governing constraint checkers reason about reachability between zones
and how many choke points each zone has — connectivity and degree — which are
graph properties. Options were (a) a positional grid where "zones" are cell
clusters, or (b) an explicit graph whose nodes are zones and whose edges are
choke points.

## Decision

Model the map as an **undirected graph**: `MapGraph` holds `Zone[]`, `ResourceNode[]`,
and `ChokePoint[]` (each `ChokePoint` records a `FromZoneId`/`ToZoneId` edge).

## Rationale

The constraints that define a valid map are connectivity and choke-point
degree, and both are far simpler, harder to get wrong, and more directly
testable on a graph than on a grid — a grid would force every checker to
re-derive adjacency from cell coordinates, reintroducing the exact geometric
bookkeeping the constraint discipline exists to avoid. A graph also keeps
placement free-form while remaining deterministic: a zone's `GridPoint`
position is kept as an *embedding* for the spatial reasoning agents need,
but it is not the storage lattice. This mirrors the
Dungeon Generator lineage's discipline of hard checkers over free-form
generation: the generator is free to place anything anywhere, and the
checkers alone define validity.

## Consequences

- Checkers read only `ChokePoint` edges and `Zone` ids — no coordinate math.
- Zone `Id`, `ChokePoint.Id`, `ResourceNode.Id` are explicit `int`s so the
  generator, environment, and trajectories can reference entities
  deterministically (no `Guid` generation, no object identity).
- `GridPoint` positions are an optional embedding, letting later map layouts
  reuse the same graph shape.
- Kinematic traversal makes the embedding load-bearing: `Simulation.TransitTicks`
  computes an edge crossing's duration from the Manhattan distance between the
  two zones' positions, in pure integer arithmetic (`ceil` via integer math,
  no floating point), while connectivity and capacity reasoning still operate
  purely on the graph. See adr-002.
